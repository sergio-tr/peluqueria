# Document Change

Actualiza el change record y las fuentes canónicas afectadas.

El change record debe contener:

- Summary
- Recovery phase
- Scope included
- Scope excluded
- Architecture impact
- API impact
- Data/migration impact
- Security/privacy impact
- Testing evidence
- Deployment impact
- Rollback
- Documentation updated
- Remaining risks
- Verification status

Crea ADR cuando una decisión cambie estructura, responsabilidades, provider, persistencia, seguridad, despliegue o scope.
