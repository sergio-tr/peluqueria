# Implement Recovery Phase

1. Lee la sección exacta de la fase.
2. Invoca planner y architect.
3. Congela included/excluded scope.
4. Implementa mediante el especialista adecuado.
5. Ejecuta tests y build.
6. Invoca security auditor cuando aplique.
7. Invoca documentation governor.
8. Invoca independent verifier.
9. Corrige hallazgos dentro del scope.
10. No abras scope nuevo.
11. Pasa a `open-pull-request`.
