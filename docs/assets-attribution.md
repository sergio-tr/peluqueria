# Assets attribution

Catalog: 8 hairstyles. Each has **catalog** (UI hero), **AI reference** (style transfer input), and **thumbnail** (compact UI). All seed assets are **synthetic raster PNGs** generated by `scripts/generate-hairstyle-assets.mjs` — clearly labeled, non-identifiable, demo-only.

## Policy (D-05)

| Rule | Detail |
|------|--------|
| AI reference format | **Raster only** (PNG). SVG placeholders are **not** valid for smoke, benchmark, or Replicate. |
| Provenance | Recorded per row in `hairstyles.provenance` and below. |
| Usage rights | `demo-internal-only` until operator replaces with licensed or production-generated set. |
| Public smoke / benchmark | Requires operator to swap synthetics for higher-quality generated assets; pipeline accepts non-SVG paths today. |
| Regeneration | `npm run generate:hairstyle-assets` then bump `asset_version` in seed + migration backfill. |

## Asset layout

```
public/hairstyles/{slug}/catalog.png
public/hairstyles/{slug}/ai-reference.png
public/hairstyles/{slug}/thumbnail.png
```

DB columns: `catalog_image_path`, `ai_reference_image_path`, `thumbnail_image_path`, `asset_version`, `provenance`, `usage_rights`.

Current version: **1.0.0-synthetic-mvp**
