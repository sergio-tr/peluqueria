# Design system

## Dirección

Editorial, elegante, contemporánea, inclusiva. Evitar barbería genérica negro/dorado y looks AI por defecto (púrpura, cream+serif terracotta, broadsheet).

## Tokens

| Token | Uso |
|-------|-----|
| Ivory cálido | Fondo atmósfera (gradiente/patrón sutil) |
| Carbón | Texto |
| Cobre rojizo | Acento CTA |
| Verde salvia | Secundario / éxito suave |
| Display editorial | Marca / headlines |
| Sans funcional | UI / formularios |

## Marca visual

Línea SVG abstracta “hebra”: separador, progreso, marca. Brand hero-level en landing; claim no debe opacar el nombre.

## UX

- Mobile first; una decisión principal por pantalla; ≤2 CTA visibles.
- Textos breves; fotos grandes.
- Motion 180–300 ms; respetar `prefers-reduced-motion`.
- AA; empty / loading / error diseñados.
- IA como herramienta, no héroe absoluto del copy.

## Pantallas

Landing, gate, foto/crop/consent, catálogo, generación (estados), comparador, booking, solicitud enviada, confirm token, login admin, dashboard, detalle, agenda, demo inbox, privacidad, uso IA admin.

## Principios anti-plantilla

Sin cards en hero; sin badges flotantes sobre media; una composición en primer viewport.
